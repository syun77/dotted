# Asepriteで始めるドット絵練習ガイド

## この資料の目的

Asepriteの機能を、ドット絵の観察・制作・振り返りに結びつけるための実践ガイドです。最初から多機能を使いこなす必要はありません。まずは小さいキャンバスと少ない色で完成させ、少しずつアニメーションやタイル制作へ進みます。

## まず覚える制作の流れ

1. お題と制約を決める
2. シルエットを作る
3. 明暗を2～3段階に分ける
4. 必要な色だけ加える
5. 等倍表示で読めるか確認する
6. PNGやGIFに書き出す
7. 良かった点と次に直す点を1つずつ記録する

制約は上達を助けます。最初の目安は「16×16または32×32ピクセル、透明背景、4～8色、30～45分」です。

## 練習しやすい初期設定

### 1. 小さいキャンバスから始める

`File > New`で次のどちらかを選びます。

- 16×16：形を省略する力を鍛える。アイコン、道具、食べ物向け
- 32×32：立体感や細部も練習する。キャラクター、小物、建物向け

最初は`RGB`モードが扱いやすく、色を厳密に管理する段階になったら`Indexed`モードを使います。Indexedでは各ピクセルがパレットの色番号を参照するため、パレットの1色を変えると、その色を使うピクセルをまとめて変更できます。透明色用のインデックスも必要です。詳しくは[Aseprite公式：Color Mode](https://www.aseprite.org/docs/color-mode/)を参照してください。

### 2. 鉛筆を1ピクセルにする

基本は`Pencil Tool`の1 pxブラシです。自由線を引くときは、ツール上部の`Pixel-perfect`を試します。線の折れ曲がりにできる余分な角を抑えやすくなります。ただし自動で良い輪郭になるわけではないため、最後は1ピクセルずつ確認します。

### 3. グリッドは必要なときだけ表示する

`View > Grid`でグリッドを表示し、`View > Grid > Grid Settings`で間隔を設定します。

- 16×16作品：1ピクセル単位の確認には1×1、区画の把握には8×8
- 32×32作品：大きな比率を見るには8×8または16×16
- タイル制作：実際のタイルサイズと同じ値

グリッドを常時表示すると形よりマス目を追いやすくなるため、描画中は非表示、位置合わせ時だけ表示する使い方も有効です。

### 4. 等倍確認用のプレビューを出す

作業画面を拡大したまま、`View > Preview`（既定では`F7`）で等倍に近い見え方を確認します。アニメーションはプレビュー上の再生ボタンまたは`Shift+Enter`で再生できます。公式の説明は[Aseprite公式：Preview Window](https://www.aseprite.org/docs/preview-window/)にあります。

## 上達に直結するAsepriteの使い方

### 参照画像を「見る」ために使う

写真や好きな作品をそのまま縮小・トレースするのではなく、形、明暗、色の関係を観察します。

`Layer > New > New Reference Layer from File`で画像を参照レイヤーとして読み込めます。参照レイヤーは高解像度の画像を表示でき、直接描画・編集できないため、誤って素材に描き込む心配がありません。クリップボードからは`Edit > Paste Special > Paste as New Reference Layer`を使えます。詳しくは[Aseprite公式：Reference Layer](https://www.aseprite.org/docs/reference-layer/)を参照してください。

観察するときは、次の3点を言葉にしてから描き始めます。

- 外形：何があれば、その物だと判別できるか
- 明暗：最も明るい面と暗い面はどこか
- 色：面積が最大の色と、視線を集める差し色は何か

模写を公開する場合は、参照元の利用条件や作者のルールを確認し、オリジナル作品として扱わないようにします。

### レイヤーを役割別に分ける

練習中はレイヤーを増やしすぎず、次の3～4層を目安にします。

1. `reference`：参照画像
2. `sketch`：大まかな形。完成前に非表示または削除
3. `sprite`：本番のドット
4. `shadow`：必要な場合だけ影を分離

輪郭・塗り・ハイライトを細かく分けすぎると、ピクセル同士のまとまりを判断しにくくなります。小さい絵では同じレイヤー上で形と色の関係を見る練習も大切です。

### パレットで色数を意識する

最初に4色だけ置き、足りない理由を説明できるときだけ色を増やします。

- 背景または透明
- 最暗色
- 中間色
- 最明色

色相を変えながら明暗を作ると、単に同じ色へ白や黒を足すより豊かな印象になります。たとえば明部を少し黄寄り、暗部を少し青紫寄りにします。ただし、色相より先に明るさの差が読めることを優先します。

パレットの色をクリックして前景色、右クリックして背景色に設定できます。既存スプライトからパレットを作る機能もあります。操作の詳細は[Aseprite公式：Color Bar Tutorial](https://www.aseprite.org/docs/tutorial/color-bar-tutorial/)を参照してください。

### 左右対称は「土台」にだけ使う

`View > Symmetry Options`から水平・垂直の対称描画を有効にできます。正面顔、盾、壺などの比率を決める初期段階に便利です。形が整ったら対称を解除し、髪、傷、光、ポーズなどに少し差を付けると硬さが減ります。詳しくは[Aseprite公式：Symmetry](https://www.aseprite.org/docs/symmetry/)を参照してください。

### オニオンスキンで動きの差を見る

タイムラインのオニオンスキンアイコン、または既定では`F3`で前後のフレームを重ねて表示できます。表示する前後フレーム数や色合いも設定できます。詳しくは[Aseprite公式：Onion Skinning](https://www.aseprite.org/docs/onion-skinning/)を参照してください。

アニメーション練習では、最初から滑らかさを求めず、次の順に作ります。

1. 最も重要な姿勢を2枚作る（接地と蹴り出しなど）
2. 再生して動きが伝わるか確認する
3. 必要な中間フレームだけ足す
4. 各フレームの表示時間を調整する
5. 頭や胴体の体積が急に変わっていないか確認する

### タイルモードで継ぎ目を確認する

`View > Tiled Mode`を使うと、画像を上下・左右に繰り返し表示しながら描けます。床、壁、草、水などの継ぎ目を探す練習に向いています。これはパターンを描くための簡易機能で、本格的にマップを組む`Tilemap`とは別です。詳しくは[Aseprite公式：Tiled Mode](https://www.aseprite.org/docs/tiled-mode/)を参照してください。

Aseprite 1.3以降では`Layer > New > New Tilemap Layer`からタイルマップを作成できます。同じタイルを再利用しながらマップを組むため、ゲーム背景を想定した練習に適しています。詳しくは[Aseprite公式：Tilemap](https://www.aseprite.org/docs/tilemap/)を参照してください。

## 30分の基本練習

| 時間 | 内容 | Asepriteの使い方 | 狙い |
|---:|---|---|---|
| 5分 | 参照を観察し、特徴を3つ書く | Reference Layer | 描く前に形を理解する |
| 10分 | 1色でシルエットを3案作る | 16×16、1 px Pencil | 判別しやすい外形を作る |
| 10分 | 4色で明暗と素材感を付ける | Palette、Preview | 色数を抑えて立体感を出す |
| 5分 | 等倍確認と手直し | Preview、左右反転 | 崩れや不要なピクセルを見つける |

毎回完成させることを優先します。1枚を何時間も直すより、小さな完成を重ねて共通する弱点を見つけます。

## 4週間の練習メニュー

### 1週目：形と省略

- 16×16、2色で身近な物を1日3個
- 題材例：鍵、靴、カップ、果物、工具
- 同じ題材を正面・横・斜めから描く
- 評価基準：名前を伏せても何に見えるか

### 2週目：明暗と色

- 16×16または32×32、4～8色で1日1個
- 同じシルエットを「昼」「夜」「毒」「氷」など3パレットに変更
- RGBで試作した後、Indexedに変えてパレット変更の影響を観察
- 評価基準：グレースケールで見ても面の向きが読めるか

### 3週目：素材とタイル

- 木、石、金属、布、水を各1枚
- 16×16タイルをTiled Modeでつなげる
- 規則的すぎる模様を崩しつつ、大きな明暗の流れを保つ
- 評価基準：継ぎ目が目立たず、素材の違いが伝わるか

### 4週目：アニメーション

- 2フレーム：点滅、浮遊、呼吸
- 4フレーム：炎、水、待機
- 6～8フレーム：歩行
- Onion SkinningとPreviewを使い、各フレームの差と再生時の印象を両方確認
- 評価基準：静止画を見なくても動作の種類が分かるか

## テーマ別の短いドリル

### 形を鍛える

- 8×8だけで記号やアイコンを10個作る
- 1つの題材を太い形・細い形・丸い形の3案にする
- 黒一色のシルエットだけでキャラクターを区別する

### 線を鍛える

- 直線、円、S字を1 px Pencilで描き、不要な角を掃除する
- 同じ円を7×7、9×9、11×11で作る
- Pixel-perfectのオン／オフを比較し、最終結果を手で整える

### 色を鍛える

- 1枚を4色で完成させてから、3色に減らす
- 最暗色を純黒以外、最明色を純白以外にしてみる
- パレットだけ変えて、同じ形から時間帯や属性の違いを作る

### アニメーションを鍛える

- 1ピクセルの上下動だけで呼吸を表す
- 同じ4フレームで、表示時間だけを変えて重さを表す
- 先端部分を胴体より1フレーム遅らせ、髪や布の追従を作る

## 振り返りチェックリスト

### シルエット

- [ ] 等倍で題材を判別できる
- [ ] 外周に偶然できた1ピクセルの突起がない
- [ ] 左右対称に頼りすぎず、特徴がある

### 明暗と色

- [ ] 最も明るい部分と暗い部分が意図どおりに目立つ
- [ ] 似すぎて区別できない色を統合できる
- [ ] 光源の方向が途中で変わっていない
- [ ] ハイライトが素材感の説明に役立っている

### ピクセル配置

- [ ] 輪郭の段差に一貫したリズムがある
- [ ] 孤立したピクセルが意図なく残っていない
- [ ] 細部を消しても読みやすさが落ちない箇所は整理した

### アニメーション

- [ ] キーポーズだけでも動作が伝わる
- [ ] 体積と接地点が不自然に揺れていない
- [ ] ループの最初と最後が滑らかにつながる
- [ ] 等倍・実際の速度で確認した

## 保存と書き出し

- 編集用：レイヤー、フレーム、タグを保持できる`.aseprite`
- 静止画：透過対応の`.png`
- 確認・共有用アニメーション：`.gif`
- ゲーム組み込み用：`File > Export Sprite Sheet`

スプライトシートは、表示レイヤーまたは特定レイヤー、全フレームまたはタグ単位で書き出せます。詳しくは[Aseprite公式：Sprite Sheets](https://www.aseprite.org/docs/sprite-sheet/)を参照してください。

拡大版を書き出す場合は2倍、4倍、8倍などの整数倍にし、リサイズ方式は`Nearest Neighbor`を選びます。補間によるぼけを避け、元のピクセル形状を保てます。原寸のPNGも必ず残してください。

ファイル名の例：

```text
practice_2026-09-10_key_16x16.aseprite
practice_2026-09-10_key_16x16.png
practice_2026-09-10_key_16x16_x8.png
```

## 続けるための記録方法

作品ごとに次の3行だけ残します。

```text
今回の狙い：4色で金属らしさを出す
できたこと：強いハイライトで材質が伝わった
次に直すこと：輪郭の階段を滑らかにする
```

1週間ごとに作品を並べ、「今週もっとも読みやすい1枚」「同じ失敗が出た箇所」「来週の制約」を決めます。完成枚数だけでなく、狙いを持って試し、結果を説明できた回数を上達の指標にします。

## 迷ったときの最小メニュー

1. 16×16の新規ファイルを作る
2. 4色を選ぶ
3. 身近な物を1つ、20分で描く
4. Previewで等倍確認する
5. PNGに書き出す
6. 次に直す点を1つ記録する

この6手順だけでも、毎日繰り返せば「観察・省略・配色・仕上げ」の一連の練習になります。
