# ドット絵練習ガイド

## 上達の基本方針

ドット絵の上達には、ただ数を描くのではなく、**形・色・情報量を制限し、目的を持って反復すること**が重要です。

普通の絵が情報を描き込む技術だとすれば、ドット絵は**少ないドットで意味を伝える情報圧縮の技術**です。特にゲーム用素材では、一枚絵としての美しさより、小さな画面で役割や動きが瞬時に伝わることを優先します。

ゲーム用ドット絵の基本的な優先順位は次のとおりです。

1. 視認性
2. シルエット
3. アニメーション
4. 色
5. 細部

## まず身につけたい基礎

### シルエットで形を伝える

模様や陰影より先に、1色で塗りつぶしても「人」「剣」「木」「敵」などを判別できる形を目指します。

キャラクターは次の順で組み立てると崩れにくくなります。

1. 頭・胴体・腕・脚
2. ポーズ
3. 服や装備
4. 陰影

16×16や32×32では、顔の描き込みよりも、頭の形、肩幅、手足の向き、武器の位置が重要です。

### 小さな解像度で練習する

最初は8×8、16×16、32×32程度で練習します。小さな解像度では、必要なドット、省略する部分、強調する特徴を考えざるを得ないため、情報の取捨選択を効率よく学べます。

基本は16×16とし、同じ題材を次の順で描く練習も効果的です。

```text
16×16で基本形を作る
↓
8×8で特徴を絞り込む
↓
32×32で増えた情報量を整理する
```

### 色数を制限する

最初は、次の4色程度から始めます。

- 背景色
- ベース色
- 暗部
- 明部

キャラクターは4〜8色程度でも十分に成立します。色を増やす前に、明度差があるか、背景から浮いて見えるか、影と本体を区別できるかを確認します。ゲーム画面の視認性には、色相の違いよりも明度差が強く影響します。

### 線ではなく面で考える

輪郭線を描いて中を塗るよりも、**色の塊を配置する**と考えます。

たとえば木なら、「幹を描いてから葉を描く」のではなく、次の順で大きな面から作ります。

1. 葉の大きな塊
2. 暗い塊
3. 明るい塊
4. 幹

大きな面から組み立てると、細かいノイズが減り、読みやすい絵になります。

### ジャギーのリズムを整える

曲線では、ドットが作る階段の長さと間隔を観察します。規則的な階段は滑らかに、不規則な階段は輪郭のがたつきとして見えます。

```text
滑らかな例        がたつく例
■■■              ■■■■
  ■■                  ■
    ■■               ■■■
```

輪郭を拡大して、階段の幅が急に変わっていないか、意図しない突起がないかを確認します。

### アンチエイリアスを使いすぎない

中間色を増やして滑らかにしようとすると、かえって輪郭がぼやけます。基本は「輪郭、ベース色、必要最低限の補助ドット」で構成し、ゲーム用スプライトでは輪郭の明瞭さを優先します。

### 実物を記号化する

写真をそのまま縮小するのではなく、その対象だと認識させる特徴を抽出します。たとえば猫なら、三角形の耳、大きな頭、尻尾、目などを優先します。

ドット絵はリアルな再現ではなく、特徴を強調したアイコン化に近い表現です。

## 効果的な学習方法

### 模写して構造を理解する

8bit〜16bit時代のゲームをはじめ、小さなスプライトは省略表現の優れた教材です。単にコピーするのではなく、「なぜこの1ドットが必要なのか」を考えながら模写します。

観察する項目は次のとおりです。

- シルエット
- 使用色数と明度差
- ハイライトと影の位置
- 輪郭線を省略している場所
- 特徴を作る1ドット
- 背景とのコントラスト

模写後は参考画像を閉じ、記憶だけでもう一度描きます。再現できなかった部分を確認すると、見た目ではなく構造を理解できているかが分かります。

> 模写した作品を公開・配布する場合は、元作品の権利や利用条件を確認します。模写は個人練習を基本とし、公開作品にはオリジナル素材を使います。

### 完成後に削る

描き足すだけでなく、「この1ドットは本当に必要か」と確認して不要な情報を削ります。削った前後を比べ、意味を損なわず形が明瞭になったなら、削った状態を採用します。

### 同じ題材を描き直す

毎回違うものを描くより、同じ題材を繰り返し改善すると、自分の弱点を発見しやすくなります。

```text
スライム v1 → 比較・分析 → v2 → 翌日に確認 → v3
```

古い版を残し、シルエット、色数、視認性、不要なドットがどう変わったかを比べます。

### ゲーム画面で確認する

素材単体だけで判断せず、実際の背景色、表示倍率、周囲のキャラクターやUIと一緒に配置します。等倍表示でも役割が伝わるか、背景に埋もれないか、他の素材と大きさや絵柄が揃っているかを確認します。

## 30〜60分の基本メニュー

| 時間 | 内容 | 目的 |
| --- | --- | --- |
| 5分 | 8×8〜16×16で丸、箱、剣、木、顔などを1〜3個描く | 形とドットの階段に手を慣らす |
| 10〜15分 | 既存作品の小さなスプライトを同じサイズ・色数で模写する | 省略と特徴の作り方を観察する |
| 10分 | 参考を閉じて記憶から描き直す | 構造を理解できたか確認する |
| 15〜20分 | 16×16または32×32でオリジナルを1つ作る | 観察した技術を応用する |
| 5〜10分 | 不要なドットを削り、シルエットと等倍表示を確認する | 視認性を仕上げる |

時間が30分しかない日は、ウォームアップ5分、オリジナル制作20分、振り返り5分に短縮します。重要なのは、短時間でも制作と振り返りをセットにすることです。

## 曜日ごとの重点テーマ

| 曜日 | 練習テーマ | 例 |
| --- | --- | --- |
| 月 | シルエット・形 | 1色で人物、動物、道具を描く |
| 火 | 色・陰影 | 同じ形を異なる4色パレットで描く |
| 水 | キャラクター | 正面、横、後ろ、異なるポーズ |
| 木 | 背景・地形・タイル | 床、壁、草、岩と接続パターン |
| 金 | アイテム・UI・アイコン | 武器、鍵、体力、状態表示 |
| 土 | アニメーション | 待機、歩行、攻撃、被弾 |
| 日 | 描き直し・比較 | 月曜の作品を再制作して差を記録 |

## 4週間の練習プラン

### 1週目：8×8〜16×16の単純な物体

木、剣、鍵、宝箱、ハート、果物などを描きます。形の識別、色数の制限、ジャギーの整理に集中します。

### 2週目：16×16のキャラクター

正面、横向き、後ろ向き、異なるポーズを作ります。顔の細部より、頭身、肩幅、手足の向き、装備の位置を優先します。

### 3週目：32×32のキャラクターと背景

人物に加え、床、壁、草、岩などを同じパレットで作ります。単体の完成度だけでなく、絵柄、明度、縮尺の統一を確認します。

### 4週目：短いアニメーション

次の順で練習します。

- 待機：2フレーム
- 歩行：4フレーム
- 攻撃：4〜6フレーム
- 被弾：2〜3フレーム

最初にキーとなるポーズを作り、必要な場合だけ中間フレームを追加します。

```text
構える → 振りかぶる → 攻撃 → 戻る
```

細かく滑らかに動かすことよりも、各ポーズの違いが等倍表示で明確に伝わることを優先します。

## 小さな架空ゲームを作る実践課題

1週間で、ひとつのゲームに属する素材セットを作ります。

- 主人公：1体
- 敵：3体
- アイテム：5個
- 床タイル：4個
- 壁タイル：4個
- UIアイコン：5個
- 主人公の歩行アニメーション

この課題では、単体の絵だけでなく、パレット、サイズ感、輪郭、世界観、ゲーム画面での視認性を統一する力を鍛えます。

## 1bit環境で意識すること

Playdateのような低解像度・1bit環境では色彩を使えないため、次の要素が特に重要です。

- 白と黒の面積比
- 輪郭と余白
- ディザリングの密度
- 模様の違い
- 動きによる識別

ディザリングは陰影表現に便利ですが、細かく使いすぎるとノイズになります。まず白黒の大きな面で形を成立させ、その後で必要な場所だけに加えます。

## 制作後のチェックリスト

### 形

- [ ] 1色のシルエットでも題材が分かる
- [ ] 小さな表示倍率でもポーズや向きが分かる
- [ ] 意図しない突起や輪郭のがたつきがない

### 色

- [ ] 必要以上に色を使っていない
- [ ] 明部、ベース、暗部の明度差がある
- [ ] 実際の背景上でも埋もれない

### 情報量

- [ ] 題材を識別する特徴が強調されている
- [ ] 用途のない1ドットや細部を削った
- [ ] アンチエイリアスやディザリングがノイズになっていない

### ゲーム素材

- [ ] 他の素材とパレット、輪郭、縮尺が揃っている
- [ ] 等倍表示のゲーム画面で役割が伝わる
- [ ] アニメーションのキーとなるポーズが明確に違う

## おすすめの練習サイクル

最も効果的な流れは次のとおりです。

```text
模写
↓
分解して理解
↓
記憶で再現
↓
オリジナルへ応用
↓
ゲーム画面に配置
↓
不要なドットを削る
↓
翌日に同じ題材を描き直す
```

毎回、作品と短い振り返りを残します。「良かった点」「直す点」「次回ひとつだけ試すこと」を記録すると、描いた量を確実に改善へつなげられます。
